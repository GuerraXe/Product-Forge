## Installation
Requires Node and Python 3.

In the front-end directory, run 'npm install' once to install the node packages. Then run 'npm run dev', which starts both the backend endpoint (back-end/main.py) and the frontend. Ctrl+C stops both. To start only the frontend, run 'npm run dev:frontend'.
